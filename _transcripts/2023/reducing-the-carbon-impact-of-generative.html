6:09 We have shown that generative AI serving is a suitable candidate for geographic load shifting since its latency is weakly correlated with client location. Okay so in line with that we introduce a variety of request direction algorithms focused on hardware utilization and carbon reduction. When a compute region receives a user's request it can either be processed locally or sent to another compute region. And the choice of this region can be made on multiple criteria. In the balanced algorithm requests are directed proportional to the available resources producing equal utilization across all regions. In CarbonMin that we propose, when a user sends an inference request to the nearest cloud region, it is directed to the region with the lowest carbon intensity intensity that has available capacity. But request direction in CarbonMin is constrained by available resource capacity. And we consider the case of unlimited capacity in CarbonMin unlimited.
