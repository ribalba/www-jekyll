0:01 Hello everyone, my name is Muhammad Zubair Farooqi and I am excited to present our research on Understanding and Mitigating Webpage Data Bloat Causes and Preventive Measures. This work has been conducted by me and my colleagues including Aleksi Saarinen, Matti Pärssinen and Jukka Manner from Aalto University, Finland. We are honored to present this work at HotCarbon 24. Web pages are integral to the internet service we use daily. They have evolved from simple text-based pages to complex sites that offer services like banking, social networking and online shopping. However, this has led to significant increase in web page sizes which has a substantial environment impact due to high energy and resource consumption. The motivation behind our study stems from the need to address the growing energy and resource consumption associated with large web pages.

1:10 Prediction indicated that the ICT sector could account for up to 21% of the global electricity usage by 2030, compared to just 4.7% in 2012. It's crucial to find ways to reduce the carbon footprint of services to create more sustainable future. In our study, we analyzed 10,000 popular web pages to understand the causes of data bloat and identify ways to reduce data usage without compromising essential content. Our comprehensive analysis aims to provide actionable insights to make web services more environmentally sustainable and friendly. So, in our overall methodology, we analyzed 7,324 unique URLs using Google Lighthouse for resource and performance valuation. Detailed examination. Then, obviously, we did detailed examination of image formats, resolution and JavaScript libraries to uncover any inefficiency in the whole web page. So, in our overall setup, we emulated four devices.

2:34 One is desktop, the scrolled desktop, the whole version of the desktop website, the mobile version and the scrolled mobile version. Using the Lighthouse tool, we analyzed web pages resources and performance to gather detailed data on the factors contributing to data bloat. Our key findings revealed that the image accounts for 49% to 58% of the average web page size, while JavaScript contributes 20% to 28%. Together, the image and JavaScript make up to 77% to 78% of the total page size. We also discovered that there is significant potential for data savings, with the possibility to reduce current data usage for more than a half. The first of all is image optimization. To optimize image, we recommend replacing older formats like PNG and JPG with the modern formats like AVIF and WebP.

3:51 Additionally, resizing images to match their displayed resolution can result in substantial data saving, potentially reducing to the amount of data by 80%, which is, I think, very huge. Then there is JavaScript optimization. So for JavaScript optimization, we suggest using popular libraries that can be cached in the browser to avoid downloading the same libraries multiple times. Removing unused JavaScript can also help reduce data usage. These measures can lead to data saving for approximately 5.4 to 5.6%. So there is a web form, the web sustainability guidelines. So they provide recommendations for making web content and infrastructure more energy efficient. These include optimizing content, choosing green hosting providers and enhancing user experience through fast loading times. Our work supports these guidelines by providing concrete data and evidence. So in the results, our results shows that the average page size varies across devices, with the desktop pages averaging 3358 kilobytes and mobile pages averaging 2939 kilobytes.

So there is a potential to nearly half the web page size while maintaining the core content integrity. So the key strategies were optimizing image formats and resolution and pruning unused JavaScript libraries as we already discussed. Then obviously converging to the modern image formats. I have already discussed that WebP and some other modern image formats could be used to reduce image data size. Then resizing the image to match display resolution can save over half of the image data. We recommend several data saving strategies, including removing unused CSS and JavaScripts, applying text compressions, converting images to efficient formats and resizing them. Additionally, making data cacheable can reduce the amount of data needed for subsequent visits, enhancing overall efficiency.
